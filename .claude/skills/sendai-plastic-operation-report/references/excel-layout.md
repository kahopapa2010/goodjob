# 旧・操業日報Excel（月次ファイル）の構造

extract.py が前提にしているセル配置。レイアウトが変わった月のファイルでは、ここと extract.py を合わせて直す。

## シート
| シート | 内容 |
|---|---|
| 日報（認定） | メインの日報。**1日＝50行のブロック**が31日分（d日目の先頭行＝1+50(d-1)）。A{先頭}に日付 |
| 日報（容リ）/ 日報（32条） | 同じ形。原料処理（容リ12〜14行、32条15〜16行） |
| 日報（統合） | 3区分の合算。検証用の集計値を読む（G17/H17入荷、O17/P17処理、G30製品出荷、G37廃棄物出荷） |
| 減容品（認定） | 列 B+3k+直（D/E/N）× 行11〜90 に1袋ごとの重量（k＝日の番号0〜） |
| 入荷 / 出荷 / 出荷（容リ）/ 出荷（32条） | 1日1行（行 5+50(d-1)）。列が搬入元・出荷先。見出しは3行目（品目）・4行目（出荷先） |
| 直送 | 行6〜29が時間帯。フラフは列C+k、直送減容品は列AK+k |

## 日報ブロック内の行（先頭からの相対行）
- 3: 安全ポイント(B)、R-KYK(I)／汚泥引抜
- 4〜7: 水処理（原水槽・生物温度・放流濁度・汚泥段数）、6行目I/Mに担当班
- 8: 所定時間（Y=D直、AA=N直）／15: 休憩／16: 点検清掃定修
- 9〜11: 原料処理（I/J=D直 重量/個数、K/L=E直、M/N=N直）
- 18〜29 (X列): 工程名と予定外休止（Y=D直、AA=N直）
- 22〜29: 製品、32〜36: 廃棄物（C=品目、E/F=月初在庫の重量/個数）
- 30〜38 (X列): 設備稼働（Y=D直、AA=N前半19-24時、AB=N後半0-7時。38行＝汚泥脱水機はN直まとめ）
- 40〜50: 特記事項（D直側 A,C,D,E,F,J ／ N直側 L,M,N,O,P,T）
- AF〜AI 7〜16: ベール処理（種類・個数・開始・終了）

## 変換で気をつける点
- `=18+24` のような**定数だけの数式は手入力扱い**（CONST正規表現）。出荷の `=12290+11010` は1台1行に分解。
- 他ファイル参照の数式セル（[1]前月、[5]安全、[6]品質、[13]原料パレット出荷、[25]管理表、[35]直送計量）はキャッシュ値を読む。
  Excelで一度開いて保存し直すと値が消えることがあるので、**受け取ったファイルをそのまま使う**。
- 容リ/32条のパレット出荷は 出荷（容リ）/出荷（32条） の B,D,BL 列。品目名は 出荷!B3 / BL3。
- 出荷先の見出しに `#REF!` や `0` がある列はマスタから除外（M05で正式名称を登録し直す課題あり）。
- E直の列は数式で0固定（現在未使用）。

## 業務ルール（JUST.DBの計算項目で再現するもの）
- 実操業時間＝MAX(開梱機, 破袋機)。N直は前半＋後半を足してから比べる
- 予定外休止＝所定−実操業−（休憩＋点検清掃定修）
- 原料処理重量＝在庫平均単体重量×処理個数（D直→N直の順に按分、在庫超過なら在庫全量）
- 月曜＝定修（WEEKDAY=2）→ M09_操業カレンダーで管理
- 製品収率＝製品生産量合計÷原料処理重量、処理ペース＝原料処理重量÷実操業時間×60
